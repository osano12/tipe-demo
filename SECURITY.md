# Sécurité

Ne publiez pas une vulnérabilité ou un secret dans une issue publique. Contactez directement le propriétaire du dépôt avec une description, les étapes de reproduction et l'impact estimé.

Les clés Gemini et identifiants réseau doivent rester dans des variables d'environnement ou dans une configuration locale non versionnée. Toute valeur exposée dans Git doit être considérée comme compromise et remplacée.
